## 2. Secret scan results

Scanned all source, config, schema, markdown and tracked logs; excluded `node_modules`, `.next`, `package-lock.json`.

### ✅ Clean

- `.env`, `.env.local`, `.env.production.example` are **ignored and have never been committed** — verified with `git log --all -- '.env' '.env.local' '*.pem' '*.key'`, which returned empty.
- No API keys, bearer tokens, private keys, certificates, cloud credentials or payment keys found anywhere in tracked or untracked source.

### 🔴 H-1 — CRITICAL: hardcoded auth fallback secret published to a public repository

`src/lib/auth.ts:65`, **in commit `b9ee686`, publicly readable:**

```ts
secret: process.env.NEXTAUTH_SECRET || "super-secret-walaaplus-dev-key-123",
```

The uncommitted working tree contains a **second** fallback in two places:

```
src/lib/auth.ts:65     "walaaplus-local-dev-secret-key-123"
src/middleware.ts:15   "walaaplus-local-dev-secret-key-123"
```

**Impact.** If `NEXTAUTH_SECRET` is ever unset in a deployed environment, session tokens are signed with a value anyone can read on GitHub, permitting session forgery. No production deployment and no real users exist today, so no live system is compromised.

**Remediation.**
1. Both strings are **permanently burned**. Neither may ever be used as a secret in any environment.
2. Phase 0 Prompt 0.2 removes every fallback and adds startup environment validation that fails fast when `NEXTAUTH_SECRET` is absent.
3. Production and staging secrets must be freshly generated by the owner (`openssl rand -base64 32`).
4. History rewriting is **not** proposed. It is destructive, the remote is already published, and the practical mitigation is that the values are never used. Decision A2 in [DECISIONS-REQUIRED.md](DECISIONS-REQUIRED.md) asks whether the repository should become private.

### 🟠 H-2 — MEDIUM: hardcoded local database password

`docker-compose.yml:8` — `POSTGRES_PASSWORD: walaaplus_password`. Local development only, no exposure today. Move to an environment variable in Prompt 0.2.

### 🟡 H-3 — LOW: seed password literal

`prisma/seed.ts:8` — `admin123`. Development seed only. Acceptable while it seeds only local databases; must never seed staging or production.
